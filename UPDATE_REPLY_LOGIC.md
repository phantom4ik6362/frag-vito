# Обновление логики диалога FragVito

Бот отвечает подходящим шаблоном и задаёт максимум один вопрос. Ответ на этот вопрос или явно оставленный контакт подтверждает короткой благодарностью. При смене темы, отсутствии подходящего шаблона или ошибке бот молча завершает своё участие и оставляет обращение продавцу в Telegram. Новые сообщения из завершённого чата тоже попадают в Telegram. Бот возобновляет ответы в таком чате только после команды `resume-chat`.

При первом запуске новой версии все чаты, уже присутствующие в очереди SQLite, закрываются для автоответов. Старые шаблоны не показывают, какой вопрос реально остался без ответа, поэтому угадывать состояние опасно. База, прежние задачи, записи о ручных ответах и очередь Telegram сохраняются. При необходимости существующий тестовый чат можно заново открыть:

```bash
docker exec fragvito python manage.py resume-chat 'CHAT_ID'
```

Приветствие по объявлению опирается на заголовок, полученный по ID чата. Вводный ответ есть для уличного киоска/павильона и кофейни под ключ. Если заголовок недоступен или не даёт однозначного типа, бот молчит. Из общего шаблона убрана фиксированная цена павильона: разные объявления могут иметь разные цены.

## Ветка и PR

Распакуйте ZIP поверх ветки в корне репозитория, где лежит `app.py`.

```bash
git switch fix/reply-logic
unzip -o ~/Downloads/fragvito-reply-logic.zip
git status --short
git diff --check
python3 -m unittest discover -s tests -v
git add app.py dialogue.py manage.py telegram_notify.py dry_run_cli.py prompt.txt messages tests INSTRUCTIONS.md UPDATE_REPLY_LOGIC.md
git commit -m "Preserve context and stop Avito replies after handoff"
git push -u origin fix/reply-logic
```

Откройте PR из `fix/reply-logic` в `main`. Тесты используют имитацию Avito и модели. Для локальной проверки настроенной модели можно запустить `python3 dry_run_cli.py` и ввести заголовок объявления. В этом CLI отправки в Avito имитируются.

## VPS после слияния PR

1. Сделайте проверенный бэкап SQLite по инструкции [INSTRUCTIONS.md](INSTRUCTIONS.md#сделать-резервную-копию-sqlite). Бот во время копирования может работать.
2. Убедитесь, что текущий контейнер использует ожидаемый том. Проверьте, что в `git status --short` нет правок, которые помешают обновлению.

```bash
cd /opt/fragvito
docker inspect --format '{{range .Mounts}}{{println .Name .Destination}}{{end}}' fragvito
git status --short
```

Ожидаемый том для базы — `fragvito-data`, путь в контейнере — `/app/data`.

3. Обновите код, соберите новый образ и проверьте конфигурацию. На этом этапе старый контейнер продолжает работать. Если любая команда завершилась ошибкой, устраните её до переключения.

```bash
git switch main
git pull --ff-only origin main
docker build -t fragvito:local .
docker run --rm --env-file /etc/fragvito/bot.env \
  -e DRY_RUN=false fragvito:local python manage.py check
```

4. Остановите старый контейнер и создайте новый из собранного образа. Используйте тот же том и файл окружения. Имя `fragvito-prev` должно быть свободно. Старый контейнер остаётся остановлен.

```bash
docker stop fragvito &&
docker rename fragvito fragvito-prev &&
docker run -d --name fragvito \
  --restart unless-stopped \
  --env-file /etc/fragvito/bot.env \
  -e DRY_RUN=false \
  -v fragvito-data:/app/data \
  -p 127.0.0.1:8000:8000 \
  fragvito:local
```

Команда `docker start` запустила бы старый контейнер с прежним образом. Данные сохраняются благодаря тому, что оба контейнера настроены на один именованный том. Файл окружения VPS расположен вне репозитория.

5. Проверьте сервис и очередь. Если URL и секрет вебхука не изменились, повторная подписка не нужна.

```bash
curl -fsS --retry 5 --retry-all-errors --retry-delay 1 \
  https://bot.interviewintel.space/health
docker logs --tail 80 fragvito
docker exec fragvito python manage.py jobs
docker exec fragvito python manage.py telegram-jobs
```

6. С покупательского аккаунта напишите через карточку реального объявления о киоске в новом тестовом чате. Если используете старый тестовый чат, сначала выполните адресный `resume-chat`. Проверьте последовательно:

   - «Здравствуйте» → обзор киоска и один вопрос о городе.
   - «Казань» → одна благодарность. Собственный исходящий вебхук FragVito не должен преждевременно остановить этот сценарий.
   - Отправьте тестовый контакт отдельным сообщением → продавец видит его в Telegram, бот в Avito молчит.
   - В отдельном тестовом чате попросите перезвонить и сразу оставьте тестовый телефон → одна благодарность за контакт и уведомление продавцу.

При проблеме остановите новую версию и оставьте том на месте для диагностики. Если нужно вернуть старый контейнер, учитывайте, что старая версия читает эту же базу, но не учитывает новое состояние завершённых чатов. Не запускайте обе версии одновременно.
